# Spanish flashcards

69 Spanish–English vocabulary pairs transcribed from the supplied Chapter 1 vocabulary photo. Open `index.html` in a browser; no installation is required.

Click the extra-large card to toggle Spanish and English. Back and Next wrap through the deck and reset each card to Spanish. Arrow keys navigate; Space flips the card.

Hosted using GitHub Pages from the main branch. Pushing changes to main updates the published app automatically.
